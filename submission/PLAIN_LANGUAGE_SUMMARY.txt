A linear representation must accommodate all the label patterns in a class at once. A statistical-query learner can first ask where the data distribution places its weight and then eliminate possibilities or label regions on which the remaining candidates agree. The paper identifies a rectangle condition that makes this process require few queries. It applies the condition to classes whose common linear representations require many dimensions, and gives proper and computationally efficient implementations under the stated input models. The new lower bound shows that the logarithmic query order is optimal for typical random members of the construction. The neural-network consequence uses a deliberately engineered simulation; the question about the specified ordinary Gaussian-initialized online-SGD process remains open.
