# Independent parameter derivation, before opening the corresponding source sections

Effective expectation error is zeta, including rounding. For a beta/2 noisy median, the retained CDF endpoints give F(v) >= beta/2 - 3 zeta/2 and F(v-1) < beta/2 + 3 zeta/2. A light atom (estimated mass <= estimated beta/8) has mass <= beta/8 + 9 zeta/8, hence the median prefix is in [beta/2 - 3 zeta/2, 5 beta/8 + 21 zeta/8). A heavy atom exceeds beta/8 - 9 zeta/8, hence beta/9 when beta > 81 zeta.

Two such prefixes intersect in mass >= beta/2 - 3 zeta/2. A prefix and suffix intersect in mass <= beta/4 + 21 zeta/4. Their answers fall on opposite sides of 3 estimated beta/8 with margins (beta-23 zeta)/8 and (beta-53 zeta)/8 respectively. Thus beta > 512 zeta is sufficient, not necessary. The learner's initial continuation gives beta > epsilon/4-zeta=1023 zeta at zeta=epsilon/4096.

For a heavy residual atom, true-slope residual is constant. The two split answers are bounded below by beta/2-5 zeta/2 and 3 beta/8-37 zeta/8, including the two-error subtraction. Wrong-slope residual is injective on the target and one true split is zero: corresponding answer is <=zeta or <=2 zeta. Threshold estimated beta/8 separates these cases under beta>512 zeta. Binary location of an atom > beta/9 works with threshold estimated beta/32 because a zero answer is <=zeta and a positive answer is >beta/9-zeta.

Counting: K_k=2k^3; I_k=2k^4-[k(k+1)/2]^2. D=floor(k/(24 log2 k)). If D>=1 then k>=32, log2(8e k^3/D)<=4 log2 k, so log2(count)<=2*(2k^3)*[k/(24 log2 k)]*(4log2 k)=2k^4/3. For k>=3, I_k>=3k^4/2, hence probability <=2^(-5k^4/6). D=0 gives an empty event. ETR: 2K_k D variables; K_k^2 constraints; degree 2; coefficients +/-1 and -1; v log s=O(k^4). Scaling every factor by the same positive constant makes all finite strict scores >=1. Exact D can be computed from k^(24D)<=2^k.

Set k=ceil(c n^c) and sigma=n^ceil((4c+2)/delta). Then k^4=O_c(n^(4c)), sigma^delta>=n^(4c+2), so even 2^(C_c k^4) is <=2^(sigma^delta) eventually. Restrict full-domain encoding E_n, never re-encode at scale k. Uniform oracle values on these distinct strings are independent bits. Bad global rank implies bad restricted rank. The latter test's probability under PRF keys differs negligibly from <=2^(-k^4/2), and polynomial relation sigma=n^p preserves negligibility. log2 k<=c log2 n+log2(2c)<=5c log2 n/4 eventually; rank>D implies rank>n^c/(30 log2 n).
