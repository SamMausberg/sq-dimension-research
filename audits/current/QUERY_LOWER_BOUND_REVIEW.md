# Target-line query lower bound: corrected scope

Theorem 8 proves a new matching asymptotic query bound. It preserves the source's randomized expected-error and arbitrary valid oracle quantifiers.

## Claims that failed before the proof

1. Distinct target lines need not have distinct good improper outputs. A predictor that chooses the label supplied by the unique line of slope a through each point fits all N^2 selected parallel rows. The finite test checks this on N=2,...,8.
2. A statement for every monotone flip is false: the all-positive table has a zero-query learner.
3. A grid with 2/tau+1 responses does not directly yield the denominator log(2/tau) without controlling the extra factor. The proof instead uses ceil(1/tau) midpoint responses, each at distance at most tau from its true expectation.

## Corrected theorem

For sufficiently large N, with failure probability at most 2^(-2N^3)+N^3 exp(-N/32), every output is 3/8-good on fewer than 8N^2/[1-h_2(3/8)] selected target-line instances, and every proper output is 1/3-good on at most one. These are simultaneous matrix properties, before selecting a learner.

The unrestricted numerator is log_2 N + log_2(chi(1-8epsilon/3)/8). The proper numerator is log_2(2M)-1+log_2(1-3epsilon). Both divide by log_2 ceil(1/tau). The query order is Theta_epsilon(n) at an accuracy-dependent constant tolerance supplied by the upper theorem. The requested leading n coefficient is established for proper outputs only; it is not established for unrestricted outputs.

| Step | Adverse response or justification | Randomness |
|---|---|---|
| A fixed output is good on one row with probability at most 2^(-chi N) | Entropy bound at error 3/8 | Independent flip bits |
| A fixed output is good on s rows with probability at most 2^(-chi Ns) | Independence is across row-indexed incidences, even at shared points | Independent flip bits |
| Union bound over all 2^(2N^3) outputs and row subsets | Applied before the learner is selected | Flip matrix |
| All selected rows have at least 3N/8 negative incidences | Hoeffding with deficit N/8 gives exp(-N/32) | Flip matrix |
| A different proper row has loss at least 3/8-1/N>1/3 | Two template lines share at most one point; N>=25 | None |
| At most B^m leaves for a fixed seed | Oracle returns the interval midpoint for every query; B=ceil(1/tau) | Seed fixed |
| Error-to-success conversion | Markov: P(loss<=eta)>=1-epsilon/eta under the same quantizer policy | Learner seed |
| Comparison of averaged leaf coverage and success | No oracle is selected after observing private coins | Learner seed; oracle fixed per instance |
